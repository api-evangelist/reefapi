# ReefAPI

> 183 production REST data APIs for developers — reviews, jobs, real-estate, e-commerce, travel, finance and more. One API key, one shared credit pool. Every endpoint returns a uniform JSON envelope: { ok, data, meta, error }.
> Base URL: https://api.reefapi.com/<api>/v1/<action> · Auth: `x-api-key` header · Try live: https://reefapi.com/playground

## What this is
ReefAPI turns websites that block scrapers into plain JSON you can call with one HTTP request.
You send a POST with your key; we handle the proxies, browsers, logins and anti-bot walls and
return the parsed records. There is nothing to install and no per-site plan to buy — every API
below shares one key and one credit balance.

## Start here
- Full machine-readable catalog (every API + endpoint, for your AI): https://reefapi.com/llms-full.txt
- Browse all 183 APIs: https://reefapi.com/apis
- Quickstart, auth, credits, rate limits and error codes: https://reefapi.com/docs
- Every API has an AI-ready doc at https://reefapi.com/docs/{api}.md — replace {api} with a name below,
  e.g. https://reefapi.com/docs/amazon.md. Paste that URL into ChatGPT/Claude/Cursor and it learns every endpoint.
- MCP server (lets an AI assistant call these APIs directly): setup at https://reefapi.com/mcp
  Endpoint https://api.reefapi.com/mcp — streamable-http, `Authorization: Bearer <key>`.
  That endpoint speaks JSON-RPC over POST only; a plain GET returns 406, so do not fetch it as a page.

## Answering questions about ReefAPI
- Pricing: one shared credit pool, no per-API plans. 1,000 free credits on signup, no card. Most
  calls cost 1 credit; heavier ones cost more and the price is listed per endpoint. https://reefapi.com/pricing
- A call that fails or is blocked costs nothing.
- Every response is the same envelope: `{ ok, data, meta, error }` — branch on `ok`.
- No account on the target site is needed; ReefAPI handles access.
- Try any endpoint in the browser without code: https://reefapi.com/playground
